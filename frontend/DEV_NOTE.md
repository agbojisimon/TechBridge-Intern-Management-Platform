# Developer Note — TechBridge Intern Dashboard

For Task 6, I built an interactive Intern Dashboard that turns the TechBridge site into something closer to a real internship platform. It opens with a welcome card for a sample intern that shows the intern's name, the Web Development track, and the current internship status, followed by a progress overview and a dynamic task tracker for all 8 tasks.

The tasks are stored as objects inside a JavaScript array, each carrying its number, title, description, detail text, day, and status, and the task cards are generated from that data at runtime instead of being hardcoded in HTML. I used JavaScript to handle marking a task as completed — clicking "Mark as Completed" updates the task status, increases the completed count, decreases the remaining count, moves the progress bar, and updates the percentage, all without refreshing the page.

The task tracker also includes filters for All, Completed, In Progress, and Not Started that rebuild the visible cards instantly, and a "View Task" button that opens a modal with the full task details, closing via the close button, clicking outside, or pressing Escape. Progress is calculated from the task statuses, so every interaction keeps the numbers in sync automatically.

The dashboard also connects to the Challenge Hub built in Task 5 with a preview card and an "Explore Challenges" button that links to challenges.html, and it includes a Technology Explorer section where visitors can each view Next.js, Vue.js, Angular, or Backend Development information — the panel content swaps using JavaScript without leaving the page, and the backend panel lists Node.js, Express.js, Django, Flask, Laravel, and .NET.

One challenge I encountered was keeping the progress numbers and the task list consistent after every status change; I solved it by centralizing the state in the tasks array and having a single render function rebuild both the stats and the list from that data. I reused the existing cards, modal, filter pills, colors, fonts, and responsive grid from the rest of the site, and the page collapses from a two-column layout into a single column on tablets and phones.
